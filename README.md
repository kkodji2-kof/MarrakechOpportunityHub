#  MarrakechOpportunityHub

Plateforme interactive de collecte, d'analyse et de suivi des opportunités de stage et d'emploi à Marrakech.

##  Démo en ligne
Retrouvez l'application déployée sur Streamlit Cloud :  
👉 [marrakechopportunity.streamlit.app](https://marrakechopportunity.streamlit.app)

## 🛠️ Technologies utilisées
- **Langage** : Python 3.11
- **Framework Web** : Streamlit
- **Analyse & Visualisation** : Pandas, Plotly
- **Base de données** : SQLite / CSV

## 📁 Structure du projet
- `stages_marrakech/frontend/` : Interface utilisateur Streamlit
- `données/` : Fichiers de données et scripts d'extraction
